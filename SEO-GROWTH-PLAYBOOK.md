# Cross-brand SEO and Authority Playbook

Created: 2026-11-02. Scope: real public pages. Never publish private accounts, payments, preview, staff, child or operations routes in search.

## Nine mandatory release gates
1. Indexing: real canonical indexable 200 URLs only in sitemaps; robots rules and noindex policies are consistent.
2. Search previews: unique factual titles and descriptions; correct canonical; accessible 200-status Open Graph image.
3. Structure: one meaningful H1 per page, accessible nested headings and accurate image alternative text.
4. Schema: validate only factual Organization / LocalBusiness / ChildCare / Restaurant / Service / Product / BreadcrumbList data that fits page content.
5. Navigation: tested internal links, valid breadcrumbs, matching permanent redirects for old valuable URLs.
6. Performance: mobile p75 good Core Web Vitals (LCP <= 2.5s, INP <= 200ms, CLS <= 0.1); right-size and cache images; minimize JavaScript.
7. Security: force HTTPS, choose one apex or www version, avoid mixed content and broken slugs.
8. Analytics: confirm Search Console ownership, submit domain-specific sitemaps, inspect priority URLs and record queries/clicks/impressions/CTR.
9. Authority: earn relevant editorial references and authentic listings. Avoid paid ranking links and low-quality directory spam.

## Eight-week operational sequence
Weeks 1–2: technical indexing/redirect audit; verified Search Console and PageSpeed baseline; 20 priority URLs per public site; establish source of truth for contact/legal/business details.
Weeks 3–4: publish genuinely helpful brand-specific pages, real projects, real item inventory, approved photography and location descriptions. Add contextual internal links.
Weeks 5–6: approach real suppliers, collaborators, trade associations and editorial channels with verifiable value; seek optional editorial references, not purchased ranking links.
Weeks 7–8: inspect indexing changes, crawl issues, page/query performance and mobile field data; improve weak pages based on observed search demand.

## Monthly scorecard
Canonical domain, sitemap submission date, URLs submitted/indexed, noindex errors, canonical conflicts, impressions, clicks, CTR, branded/nonbranded queries, organic leads/orders, genuine referring domains, Core Web Vitals good-URL share. Never invent measurement values.

## Non-negotiables
Separate sitemap per canonical domain; no artificial lastmod timestamps; no indexing unfinished experiences; no false licenses, reviews, awards, partner claims, supplier endorsements or rankings. Paid ads must use sponsored/nofollow qualifying links when applicable. Google's link spam policy: https://developers.google.com/search/docs/essentials/spam-policies. Release after verified builds, mobile checks, route crawl and rollback plan.
