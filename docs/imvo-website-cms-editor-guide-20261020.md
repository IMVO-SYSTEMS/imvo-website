# IMVO Website CMS — editorial handover

Open **https://www.imvogroup.com/studio** and sign in to the configured Sanity project.

## Projects (ready for your upcoming additions)
1. In **Projects**, create a Project document, enter its real title and click **Generate** for the slug.
2. Choose the category, location, year and a meaningful summary.
3. Upload a cover image with alternative text. Add project-gallery images in the intended order, and drawings/plans when permission allows.
4. Complete the optional scope, status, area and timeline. Turn **Feature this project on IMVO homepage** on only if you want it highlighted.
5. Keep incomplete content as **Draft**. Only click **Publish** when reviewed. Sanity drafts are not public.
6. In the Projects list, drag records to change their order. Check published Projects and detail pages after the site's normal cache refresh.

## Testimonials
- **Collections → Client Testimonials** is now directly accessible.
- Enter the actual client quote, name and optional role/company/source. Add the source/context only if verified.
- Set **Show on the website** to true and **Publish**.
- Published CMS testimonials feed the boxed rotating client review section on IMVO Studio and the About page, without fabricated star ratings or sample text.
- Turn off active or unpublish to take a review off the website. An empty review collection will not show placeholder quotations.

## Team & status
- **Collections → Team Members** manages individual photographs and role descriptions.
- **Pages → Homepage** manages headings, services, page media and section controls.
- **Operations → Studio Status** manages the actual Kigali studio opening hours.
- On the public team section, the approved supplied line-drawing group artwork is intentionally used as the default, in both theme modes. Four individual approved sketches with hover/focus photograph reveal remain in use.

## Atlas
- Africa map uses public-domain Natural Earth country and populated-place data. No MapChart website code is copied.
- User-selectable country camera fits its borders within the viewport. Named cities are geographic reference labels only; they do not imply IMVO project work or offices.
- Larger countries have 8+ sourced cities. Smaller islands and countries may have fewer genuinely documented places at this source resolution; don't invent names to fill a number.
