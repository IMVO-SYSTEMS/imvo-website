# IMVO Systems

Approved red/white/charcoal developer-agency design, adapted from the inspected Vinova reference. Native routes remain under /systems. Studio and DŌMICILE retain their own pages and are linked from the footer.

Testimonials retain the wording and authors of published IMVO Group CMS feedback. The Systems selection uses general service feedback and featured reviews with explicit Group attribution. A dated snapshot of existing published feedback is used only if the CMS request fails; an intentionally empty list remains empty. Team photographs and collaborator logos are existing IMVO assets. Reference project interfaces are illustrative as requested; their provenance is retained in reference-imagery.json. Tool marks come from Simple Icons; font and icon licenses are included.

Testimonials advance every five seconds with a three-second transition. Both logo rows loop in opposite directions. Pause/play, hover/focus pause, offscreen suspension and reduced-motion support are included. The enquiry review flow submits through the existing public Group form recipient only after the visitor selects Send. Success follows a confirmed service response.

Run npm run build:cloudflare, then npm run preview:cloudflare for the exact Worker build. npm run test:systems checks every Systems route, assets, footer division links, Group routes and 404 handling against the built Worker.
